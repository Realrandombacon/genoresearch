# LOC129390416: 12p13.33 MPRA-Validated Transcriptional Silencer with Extreme Triplosensitivity Near KRAS/NSD3 Region

## Description
LOC129390416 is a functionally characterized cis-regulatory element on chromosome 12p13.33 (genomic coordinates: 26874525-26874781 on NC_000012.12, spanning approximately 256 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 11 pathogenic/likely pathogenic variants with extreme triplosensitivity: 10 copy number gains (duplications, 91%) and 1 copy number loss (deletion, 9%), indicating triplosensitivity is the overwhelmingly dominant pathogenic mechanism. This 91% duplication bias represents one of the strongest triplosensitivity signals observed in this silencer series, comparable to LOC129390835 (100% duplications) and LOC221946 (95% duplications). The 12p13 chromosomal region contains critical dosage-sensitive genes including KRAS (proto-oncogene, RAS/MAPK signaling pathway - Noonan syndrome, cardiofaciocutaneous syndrome), NSD3 (nuclear receptor binding SET domain protein 3 - chromatin modification, Wolf-Hirschhorn syndrome candidate), TUBA1B (tubulin alpha-1b - microtubule formation, neuronal migration), and multiple developmental transcription factors. As an experimentally validated silencer, LOC129390416 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially RAS pathway regulation. Duplication of this silencer causes excessive repression of target genes (potentially KRAS or NSD3), contributing to 12p duplication syndrome phenotypes including developmental delay, intellectual disability, craniofacial abnormalities, and potential RASopathy features. The extreme triplosensitivity pattern suggests this element regulates proto-oncogenes or chromatin modifiers where precise dosage is critical for cell proliferation and development.
