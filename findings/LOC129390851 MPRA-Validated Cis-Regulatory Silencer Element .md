# LOC129390851: MPRA-Validated Cis-Regulatory Silencer Element at 17q11.2 with Dosage-Sensitive Disease Association

**Date:** 2026-03-20T20:05:06.602449

## Description
LOC129390851 is a 200bp cis-regulatory element (CRE) on chromosome 17q11.2 (GRCh38: 30938281-30938481) functionally validated as a transcriptional silencer through massively parallel reporter assays (MPRA/STARR-seq) in K562 erythroleukemia cells. This element lacks canonical promoter, enhancer, or CTCF-bound insulator chromatin signatures but demonstrates repressive activity against super core promoter SCP1 in reporter assays. As a non-coding regulatory element, it has no UniProt accession, protein domains, or STRING interactions. However, ClinVar analysis reveals 18 pathogenic/likely pathogenic variants disrupting this locus, including recurrent 17q11.2 copy number losses (chr17:30614048-30999204, 30678153-32073866), duplications (chr17:30759639-31945607), and inversions (chr17:30660608-31159168). These structural variants are associated with 17q11.2 microdeletion/duplication syndromes (NF1 microdeletion region). \n\nHYPOTHESIS: LOC129390851 functions as a distal transcriptional silencer that recruits co-repressor complexes (e.g., Polycomb Repressive Complex 2, NCoR/SMRT) to establish repressive chromatin marks (H3K27me3) at target gene promoters within the 17q11.2 topologically associating domain. The silencer likely regulates dosage of neighboring genes such as NF1, SUZ12, or EGF through long-range chromatin looping. CNVs disrupting this element cause haploinsufficiency of silencer function, leading to ectopic overexpression of target oncogenes or developmental regulators. This epigenetic dysregulation contributes to the neurofibromatosis type 1 (NF1) microdeletion syndrome phenotype, where larger deletions encompassing LOC129390851 show more severe clinical presentations than point mutations in NF1 alone.
