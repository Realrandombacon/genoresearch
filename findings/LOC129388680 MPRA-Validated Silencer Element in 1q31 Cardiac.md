# LOC129388680: MPRA-Validated Silencer Element in 1q31 Cardiac Arrhythmia and Coagulation Critical Region

## Description
LOC129388680 (Gene ID: 129388680) is a functionally validated cis-regulatory silencer element mapping to chromosome 1q31.1 (189,810,765-189,810,965 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak549 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 5 pathogenic copy number variants including 1q24.3-31.2 deletion (20.1 Mb), 1q31.1-32.1 deletion (10.6 Mb), 1q25.2-31.3 deletion (19.7 Mb), 1q25.2-32.1 deletion (20.7 Mb), and 1q31.1-42.11 duplication (37.2 Mb) - 1q rearrangements cause developmental delay, intellectual disability, craniofacial dysmorphism, cardiac defects, and coagulation abnormalities; (4) No HPA expression (non-coding - Ensembl ID could not be resolved); (5) No STRING interactions or InterPro domains (non-coding). The 1q31 region contains RYR2 (ryanodine receptor 2, 1q31.1, cardiac sarcoplasmic reticulum calcium release channel, catecholaminergic polymorphic ventricular tachycardia, arrhythmogenic right ventricular dysplasia), F3 (tissue factor/coagulation factor III, 1q31.1, extrinsic coagulation pathway initiation), and multiple developmental transcription factors. 1q31 deletions cause RYR2 haploinsufficiency leading to cardiac arrhythmias; F3 deficiency causes bleeding diathesis. Mechanistic hypothesis: LOC129388680 functions as a transcriptional silencer that represses gene expression in hematopoietic or cardiac contexts. The element likely recruits co-repressor complexes (e.g., Polycomb repressive complex 2, NuRD, or HDAC-containing complexes) via sequence-specific DNA-binding proteins to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 1q31 is gene-dense with cardiac calcium channels and coagulation factors; silencer disruption via CNVs alters TAD architecture and long-range regulation of RYR2, F3, and neighboring genes. RYR2 mutations cause lethal ventricular arrhythmias; F3 deficiency impairs thrombin generation. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes.
