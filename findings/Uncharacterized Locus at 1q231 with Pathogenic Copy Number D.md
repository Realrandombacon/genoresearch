# Uncharacterized Locus at 1q23.1 with Pathogenic Copy Number Duplications

## Description
LOC105371458 is an uncharacterized genomic locus on chromosome 1q23.1 (NC_000001.11:157925966-157949070) spanning approximately 23.1 kb. No UniProt accession was identified, precluding InterPro domain analysis and AlphaFold structure prediction. STRING database returned no protein interaction partners, confirming absence of canonical protein-coding function. Human Protein Atlas resolved this locus to Ensembl ID ENSG00000291226 but found no detectable protein expression in surveyed tissues. However, ClinVar analysis reveals 2 pathogenic/likely pathogenic variants in this region, both copy number gains (duplications): chr1:149854269-180267197 and chr1:157747246-176021247. These large structural variants span the 1q21.2-25.2 region and are associated with 1q21.1 duplication syndrome phenotypes including developmental delay, intellectual disability, dysmorphic features, and congenital anomalies. The 1q23.1 region contains several dosage-sensitive genes including the FCGR gene cluster (Fc gamma receptors) and is known for recurrent copy number variations. LOC105371458 likely functions as part of a cis-regulatory landscape or encodes a non-coding RNA whose duplication contributes to 1q21.1 duplication syndrome pathogenesis through gene dosage effects. The absence of protein-coding features combined with pathogenic CNV burden suggests this locus resides within a critical dosage-sensitive genomic region where copy number alteration disrupts normal neurodevelopmental processes.
