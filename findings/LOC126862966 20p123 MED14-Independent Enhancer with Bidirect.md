# LOC126862966: 20p12.3 MED14-Independent Enhancer with Bidirectional Copy Number Pathogenicity

## Description
LOC126862966 is an uncharacterized cis-regulatory element (CRE) at chromosome 20p12.3 (genomic coordinates 7856402-7857601, ~1.2kb span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through STARR-seq massively parallel reporter assays (MPRAs). The gene_info summary identifies this as a MED14-INDEPENDENT GROUP 3 ENHANCER that was experimentally validated in HCT116 colorectal carcinoma cells. Critically, this enhancer depends on BRD2, BRD4, P300/CBP, and CDK7 cofactors but shows limited or no dependence on the MED14 core Mediator complex subunit. This cofactor profile distinguishes it from canonical Mediator-dependent enhancers and suggests it operates through BET-dependent chromatin remodeling mechanisms. ClinVar contains 14 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. STRIKINGLY, this locus shows BIDIRECTIONAL pathogenicity: 12 copy number GAINS (chr20:87153-23635465x3, chr20:80928-18688031x3, chr20:1269303-8626911x3, chr20:80927-26324843x3, chr20:80106-13029401x3, chr20:99557-64277321x3, chr20:80106-30227427x3, chr20:89939-19071495x3, and 4 additional amplifications) AND 2 copy number LOSSES (chr20:6617695-13392559x1, chr20:7566644-11028694x1). This bidirectional pattern contrasts sharply with LOC126863081 (20q enhancer with only gains) and indicates strict dosage requirements — both enhancer overdosage and haploinsufficiency cause disease. The 20p12 region contains genes involved in cell proliferation and differentiation. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with strong clinical relevance — the BRD2/BRD4/CDK7-dependent enhancer activity in HCT116 cells combined with bidirectional pathogenicity suggests LOC126862966 functions as a dosage-critical enhancer controlling 20p gene expression, where both amplification (oncogenic overexpression) and deletion (haploinsufficiency) disrupt normal cellular homeostasis.
