## Description
LOC126863081 is an uncharacterized cis-regulatory element (CRE) at chromosome 20q13.2 (genomic coordinates 61963297-61964496, ~1.2kb span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through STARR-seq massively parallel reporter assays (MPRAs). The gene_info summary identifies this as a BRD4-INDEPENDENT GROUP 4 ENHANCER that was experimentally validated in HCT116 colorectal carcinoma cells. Critically, this enhancer depends on BRD2, P300/CBP, MED14, and CDK7 cofactors but shows limited or no dependence on the BRD4 bromodomain protein. This cofactor dependency profile distinguishes it from canonical BET-dependent enhancers and suggests it operates through alternative chromatin remodeling mechanisms. ClinVar contains 8 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. STRIKINGLY, all 8 variants are copy number GAINS/DUPLICATIONS spanning 20q regions (chr20:50805746-64334135, chr20:53236165-64284202x3, chr20:57229415-64273089x3, chr20:61326549-64277326x3, chr20:56198032-64277321x3, chr20:99557-64277321x3, chr20:59041966-64277321x3, chr20:44787704-64277321x3). The exclusive presence of copy number gains (no deletions) indicates that enhancer OVERDOSAGE drives pathology — extra copies of this regulatory element likely cause inappropriate overexpression of target oncogenes. The 20q13 amplification is a well-established oncogenic event in colorectal, breast, and ovarian cancers. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with strong cancer relevance — the BRD2/CDK7-dependent enhancer activity in HCT116 cells combined with exclusive gain pathogenicity suggests LOC126863081 functions as a dosage-sensitive enhancer controlling 20q13 oncogene expression (potentially AURKA, SRC, or ZNF217 which map to this amplicon).
