## Description
LOC100288175 (Gene ID: 100288175) maps to chromosome 1p36.33 (1,059,733-1,066,452 bp), within the well-characterized 1p36 deletion syndrome critical region. Despite annotation as "uncharacterized", multiple evidence lines suggest this is not a canonical protein-coding gene: (1) No UniProt accession after extensive searches; (2) No STRING protein interactions; (3) No HPA expression data; (4) No NCBI nucleotide transcripts found. However, ClinVar contains 64 pathogenic/likely pathogenic variants, predominantly large copy number variants (CNVs) including deletions (1p36.33-36.22, 844kb-9.3Mb) and duplications spanning the telomeric region. These CNVs are associated with 1p36 deletion syndrome phenotypes: developmental delay, intellectual disability, cardiomyopathy, and dysmorphic features. The genomic span is only ~6.7 KB—too small for a typical protein-coding gene. Mechanistic hypothesis: LOC100288175 likely represents a cis-regulatory element (enhancer, silencer, or lncRNA) rather than protein-coding sequence. The pathogenic CNVs disrupt long-range chromatin interactions or regulatory RNA transcription, affecting expression of neighboring genes in the 1p36 cluster (e.g., PRDM16, SKI, GABRD). This represents a class of "dark genes" that are functional non-coding elements misannotated as protein-coding due to Ensembl/RefSeq prediction pipelines. The high CNV burden indicates extreme dosage sensitivity—haploinsufficiency causes severe neurodevelopmental phenotypes.
