# ZNF699: KRAB-ZNF Transcriptional Repressor with 25 Pathogenic Variants Linked to Deafness and Intellectual Disability

**Date:** 2026-03-23T07:47:19.171160

**Quality Score:** 3.8/10  (E=6.3, D=1.3) [MODERATE]

## Description
ZNF699 (UniProt Q32M78, 642 aa) is a Krüppel-associated box (KRAB) domain-containing C2H2 zinc finger transcriptional repressor mapping to chromosome 19p13.2. Domain architecture: N-terminal KRAB repressor domain (PF01352, IPR001909, residues 18-90) followed by three tandem C2H2 zinc finger DNA-binding domains (PF00096, IPR013087, residues 196-301). The KRAB domain recruits TRIM28/KAP1 corepressor complex which assembles heterochromatin machinery (SETDB1 histone methyltransferase, HP1, NuRD complex, DNA methyltransferases) to establish H3K9me3 repressive marks. STRING interactions confirm functional partnerships: TRIM28 (0.411, canonical KRAB cofactor), KMT2D (0.411, H3K4 methyltransferase antagonist), RNH1 (0.687, ribonuclease H1), ANG (0.544, angiogenin), AGT (0.509, angiotensinogen), REN (0.421, renin), OR7G1 (0.434, olfactory receptor). HPA classifies ZNF699 as transcription factor with nuclear localization, low tissue specificity but detected in many tissues, cell type-enhanced expression pattern. Clinical significance is substantial: ClinVar contains 25 pathogenic/likely pathogenic variants including multiple truncating mutations (p.Lys276Ter, p.Glu120Ter, p.Arg443Ter, p.Gln179Ter, p.His497fs, p.Glu141fs, p.Cys113fs, p.Glu367fs, p.His437fs) and missense variant p.Gly96Cys in KRAB domain. HPA associates ZNF699 with deafness and intellectual disability phenotypes. Mechanistic hypothesis: ZNF699 functions as sequence-specific transcriptional silencer recognizing GC-rich motifs via C2H2 zinc finger array, recruiting TRIM28/KAP1-SETDB1 heterochromatin complex to repress target genes in neural development, auditory system maintenance, and cognitive function pathways. Truncating variants abolish DNA-binding (C-terminal zinc finger deletions) or corepressor recruitment (N-terminal KRAB mutations), causing haploinsufficiency. Target genes likely include neurodevelopmental regulators, synaptic plasticity factors, and cochlear hair cell maintenance genes. 19p13.2 locus is gene-dense; ZNF699 may regulate chromatin domain organization via CTCF/cohesin interactions. This represents a clinically actionable dark gene with clear disease mechanism.
