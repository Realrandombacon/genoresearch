# LOC129390839: MPRA-Validated Silencer Element in 17p13 Critical Tumor Suppressor and Neurodevelopmental Region

## Description
LOC129390839 (Gene ID: 129390839) is a functionally validated cis-regulatory silencer element mapping to chromosome 17p13.3 (13,584,078-13,584,278 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak2739 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 3 pathogenic copy number variants including 17p13.3-12 duplications (14.6 Mb), 17p12-11.2 duplications (7.1 Mb), and single allele duplication - 17p rearrangements cause Miller-Dieker syndrome (lissencephaly, severe intellectual disability), Charcot-Marie-Tooth type 1A (PMP22 duplication), and cancer predisposition; (4) No HPA expression (non-coding - Ensembl ID could not be resolved); (5) No STRING interactions or InterPro domains (non-coding). The 17p13 region contains TP53 (tumor protein p53, 17p13.1, most frequently mutated gene in human cancer, cell cycle arrest, apoptosis, DNA repair), LIS1/PAFAH1B1 (17p13.3, lissencephaly-1, neuronal migration), YWHAQ/14-3-3θ (17p13.2, signal transduction), and numerous imprinted loci. 17p deletions cause Li-Fraumeni syndrome (germline TP53 mutations) and myeloid malignancies (del(17p) in AML/MDS). Mechanistic hypothesis: LOC129390839 functions as a transcriptional silencer that represses gene expression in hematopoietic or neural contexts. The element likely recruits co-repressor complexes (e.g., Polycomb repressive complex 2, NuRD, or HDAC-containing complexes) via sequence-specific DNA-binding proteins to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 17p is gene-dense with critical tumor suppressors and neurodevelopmental genes; silencer disruption via CNVs alters TAD architecture and long-range regulation of TP53, LIS1, and neighboring genes. TP53 haploinsufficiency causes Li-Fraumeni syndrome; LIS1 loss causes lissencephaly. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes.
