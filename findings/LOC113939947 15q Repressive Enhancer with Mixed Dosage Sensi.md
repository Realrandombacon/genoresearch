## Description
LOC113939947 is a Sharpr-MPRA regulatory region 5793 located on chromosome 15q25.2 (genomic coordinates: 82663176-82663470 on NC_000015.10). This 295 bp genomic sequence was predicted as a transcriptional regulatory region based on ENCODE chromatin state analysis and experimentally validated as a functional repressive element (silencer) using Sharpr-MPRA in HepG2 liver carcinoma cells. As a non-coding regulatory element, it lacks protein-coding potential (no UniProt entry, no InterPro domains, no AlphaFold structure, no STRING interactions, no HPA protein expression). ClinVar analysis identified 8 pathogenic/likely pathogenic variants: 4 copy number losses (deletions), 3 copy number gains (duplications), and 1 single nucleotide variant affecting AP3B2 (c.2515C>T p.Gln839Ter and c.2505_2530dup p.Pro844fs), indicating mixed dosage sensitivity. The variant count (8 vs 7 for LOC113939953, 3 for LOC113960610, 11 for LOC113939970, 21 for LOC114004412) suggests moderate clinical penetrance. The 15q25.2 chromosomal region contains AP3B2 (adaptor-related protein complex 3 beta 2 subunit - variants cause Hermansky-Pudlak syndrome-like disorder), CHRNA3/CHRNA4/CHRNB4 nicotinic acetylcholine receptor gene cluster (associated with autosomal dominant nocturnal frontal lobe epilepsy and nicotine addiction), and HNF4A upstream regulatory elements. As a repressive enhancer/silencer, this element likely suppresses expression of one or more target genes in cis within the 15q domain. The mixed dosage sensitivity pattern (4 losses, 3 gains, 1 SNV) suggests this regulatory element maintains balanced expression of target genes - both loss and gain disrupt homeostasis. This element may contribute to 15q deletion/duplication syndromes, epilepsy through nicotinic receptor pathway dysregulation, or metabolic disorders through HNF4A pathway effects.
