## Description

Disease mechanism: Biallelic MRPL49 variants cause COXPD via: (a) Ribosome destabilization - truncated proteins (Gln155Ter, Val42fs) or misfolded mutants (Arg88His) fail to incorporate into 39S, reducing functional ribosome pool; (b) Translation fidelity loss - altered PTC geometry increases error rates, producing misfolded OXPHOS subunits prone to degradation; (c) Tissue-specific vulnerability - high-energy tissues (cochlea, brain white matter, ovary) depend on efficient mitochondrial translation; MRPL49 deficiency causes energy failure, ROS accumulation, and cell death; (d) Haploinsufficiency vs hypomorphism - null alleles cause severe early-onset disease, while hypomorphic missense variants allow residual function with later-onset phenotypes (ovarian insufficiency, dystonia). The universal expression pattern reflects essential housekeeping function, yet clinical heterogeneity suggests modifier genes or tissue-specific thresholds for mitochondrial translation capacity.
