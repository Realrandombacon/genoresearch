## Description
LOC126861570 is an uncharacterized cis-regulatory element (CRE) at chromosome 12q15 (genomic coordinates 71725254-71726466, ~1.2kb span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through STARR-seq massively parallel reporter assays (MPRAs). The gene_info summary identifies this as a MED14-INDEPENDENT GROUP 3 ENHANCER that was experimentally validated in HCT116 colorectal carcinoma cells. Critically, this enhancer depends on BRD2, BRD4, P300/CBP, and CDK7 cofactors but shows LIMITED OR NO DEPENDENCE on the MED14 core Mediator complex subunit. This cofactor profile distinguishes it from canonical Mediator-dependent enhancers and suggests it operates through BET-dependent chromatin remodeling mechanisms independent of core Mediator recruitment. ClinVar contains 4 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. STRIKINGLY, this locus shows BIDIRECTIONAL pathogenicity: 1 copy number GAIN (chr12:121271-133196807x3) AND 3 copy number LOSSES (chr12:69769737-76964217x1, chr12:68011417-75383054x1, chr12:70337484-81761145x1). This bidirectional pattern indicates strict dosage requirements — both enhancer overdosage and haploinsufficiency cause disease. The 12q15 region contains genes including MGRN1 (maher E3 ubiquitin protein ligase 1), OAZ2 (ornithine decarboxylase antizyme 2), and others involved in ubiquitination and cell cycle regulation. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with clinical relevance — the BRD2/BRD4/P300/CBP/CDK7-dependent enhancer activity in HCT116 cells combined with bidirectional pathogenicity suggests LOC126861570 functions as a dosage-critical enhancer controlling 12q15 gene expression, where both amplification and deletion disrupt cellular homeostasis.
