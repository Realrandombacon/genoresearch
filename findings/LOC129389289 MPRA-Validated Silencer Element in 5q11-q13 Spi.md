# LOC129389289: MPRA-Validated Silencer Element in 5q11-q13 Spinal Muscular Atrophy and Myelodysplastic Critical Region

## Description
LOC129389289 (Gene ID: 129389289) is a functionally validated cis-regulatory silencer element mapping to chromosome 5q11.2 (59,713,208-59,713,408 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak5261 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 5 pathogenic copy number variants including 5q11.2-13.2 deletion (14.7 Mb), 5p15.33-q13.3 duplication (74.4 Mb), 5p13.2-q12.1 duplication (26.7 Mb), 5q11.2-12.1 duplication (4.8 Mb), and 5q11.1-12.1 deletion (12.9 Mb) - 5q rearrangements cause spinal muscular atrophy, myelodysplastic syndrome (5q- syndrome), developmental delay, and intellectual disability; (4) No HPA expression expected (non-coding); (5) No STRING interactions or InterPro domains (non-coding). The 5q11-q13 region contains SMN1/SMN2 (survival motor neuron 1/2, 5q13.2, spinal muscular atrophy type I-IV, RNA splicing), multiple homeobox genes (HOXA cluster, 5q31, embryonic patterning), and cytokine gene cluster (IL-4, IL-5, IL-13, 5q31, Th2 immune response). 5q- syndrome (interstitial 5q deletion) causes refractory anemia with ring sideroblasts in myelodysplastic syndrome. Mechanistic hypothesis: LOC129389289 functions as a transcriptional silencer that represses gene expression in hematopoietic or neuronal contexts. The element likely recruits co-repressor complexes (e.g., Polycomb repressive complex 2, NuRD, or HDAC-containing complexes) via sequence-specific DNA-binding proteins to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 5q11-q13 is gene-dense with motor neuron survival factors and hematopoietic regulators; silencer disruption via CNVs alters TAD architecture and long-range regulation of SMN1/2, HOX genes, and cytokine cluster. SMN1 loss causes motor neuron degeneration and muscle atrophy; 5q- syndrome causes haploinsufficiency of multiple tumor suppressors (RPS14, EGR1, miR-145/146a). This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes.
