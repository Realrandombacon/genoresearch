# LOC129390296: 11q13.2 MPRA-Validated Transcriptional Silencer with Deletion-Predominant Pathogenicity Near MEN1/FGF Region

## Description
LOC129390296 is a functionally characterized cis-regulatory element on chromosome 11q13.2 (genomic coordinates: 67588054-67588412 on NC_000011.10, spanning approximately 358 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 5 pathogenic/likely pathogenic variants with deletion-predominant pathogenicity: 4 copy number losses (deletions, 80%) and 1 copy number gain (duplication, 20%), indicating haploinsufficiency is the primary pathogenic mechanism. This 80% deletion bias contrasts sharply with triplosensitivity patterns seen in other silencers (LOC129390366: 100% duplications; LOC129390416: 91% duplications), suggesting 11q13.2 silencers are predominantly haploinsufficiency-critical. The 11q13 chromosomal region contains critical dosage-sensitive genes including MEN1 (menin - multiple endocrine neoplasia type 1, tumor suppressor), FGF3/FGF4 (fibroblast growth factors - embryonic development, inner ear formation), CCND1 (cyclin D1 - cell cycle regulation, G1/S transition), and PAK1 (p21-activated kinase 1 - cytoskeleton regulation). As an experimentally validated silencer, LOC129390296 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially endocrine development. Loss of this silencer causes derepression/overexpression of target genes (potentially MEN1, FGF3/4, or CCND1), contributing to 11q13 deletion syndrome phenotypes including developmental delay, endocrine tumors (via MEN1 pathway), skeletal/inner ear abnormalities (via FGF pathway), and cell cycle dysregulation. The haploinsufficiency pattern suggests this element regulates tumor suppressors or developmental genes where loss of repression is pathogenic.
