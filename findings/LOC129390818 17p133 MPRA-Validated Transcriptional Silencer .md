# LOC129390818: 17p13.3 MPRA-Validated Transcriptional Silencer with Duplication-Predominant Pathogenicity Near TP53/LIS1 Region

**Date:** 2026-03-19T03:05:47.494580

**Quality Score:** 3.3/10  (E=4.4, D=2.2) [WEAK]

## Description
LOC129390818 is a functionally characterized cis-regulatory element on chromosome 17p13.3 (genomic coordinates: 1198285-1198489 on NC_000017.11, spanning approximately 204 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 36 pathogenic/likely pathogenic variants with duplication-predominant pathogenicity: approximately 25-27 copy number gains (duplications) and 9-11 copy number losses (deletions), indicating triplosensitivity is the primary pathogenic mechanism (~70% gains vs ~30% losses). This duplication bias is similar to LOC129390835 (100% duplications) and LOC221946 (95% duplications), suggesting 17p13.3 silencers are predominantly triplosensitivity-critical. The 17p13.3 chromosomal region contains critical dosage-sensitive genes including TP53 (tumor protein p53 - cell cycle checkpoint, tumor suppressor, Li-Fraumeni syndrome), PAFAH1B1/LIS1 (lissencephaly-1 - neuronal migration, brain development, lissencephaly type 1), and YWHA14 (14-3-3 protein). As an experimentally validated silencer, LOC129390818 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially neural development. Duplication of this silencer causes excessive repression of target genes (potentially TP53 or LIS1), contributing to 17p13.3 duplication syndrome phenotypes including developmental delay, intellectual disability, lissencephaly, and increased cancer predisposition. The high variant count (36 CNVs) indicates this element is clinically significant and under strong dosage constraint.
