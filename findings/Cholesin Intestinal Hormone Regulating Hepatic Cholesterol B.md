# Cholesin: Intestinal Hormone Regulating Hepatic Cholesterol Biosynthesis via WKF Domain

**Date:** 2026-03-18T18:30:12.208308

**Quality Score:** 4.7/10  (E=6.1, D=3.3) [MODERATE]

## Description
CHLSN (cholesin) encodes a 194-amino acid hormone (UniProt Q9BRJ6) secreted from intestinal cells in response to dietary cholesterol. It functions as an endocrine signal traveling to the liver where it inhibits cholesterol biosynthetic pathways and VLDL secretion, ultimately reducing circulating cholesterol levels. The protein contains a conserved WKF domain (IPR019327/PF10180) spanning residues 104-165, which likely mediates receptor binding or signal transduction. AlphaFold predicts a well-folded structure with global pLDDT of 73.4, indicating confident structural modeling. HPA data shows ubiquitous expression across all tissues with nucleoplasmic and nucleolar localization, though the primary functional site is intestinal epithelium. ClinVar contains 42 pathogenic/likely pathogenic variants including copy number gains/losses and splice site mutations, suggesting clinical relevance in cholesterol metabolism disorders. Orthologs in mouse (195 aa, Q9CXL3) and rat (193 aa, Q5I0E3) show strong sequence conservation, indicating evolutionary pressure to maintain this regulatory function. The WKF domain represents a protein family of unknown function (DUF-like), making CHLSN a key representative for understanding this domain family.
