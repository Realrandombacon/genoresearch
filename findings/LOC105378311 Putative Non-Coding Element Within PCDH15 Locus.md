# LOC105378311: Putative Non-Coding Element Within PCDH15 Locus Associated with Pathogenic Variants

**Date:** 2026-03-20T12:10:03.103135

**Quality Score:** 4.1/10  (E=5.5, D=2.7) [MODERATE]

## Description
LOC105378311 is an uncharacterized genomic locus on chromosome 10q21.1 (spanning 54,486,229-54,656,050 bp, ~170kb region) that lacks protein-coding annotation. Critical finding: ClinVar analysis reveals 20 pathogenic/likely pathogenic variants mapped to this locus, but all variant annotations reference PCDH15 transcript NM_001384140.1 (protocadherin-15). This strongly suggests LOC105378311 represents either: (1) an alternative locus designation overlapping the PCDH15 gene region, (2) a long non-coding RNA within the PCDH15 locus, or (3) a regulatory element controlling PCDH15 expression. PCDH15 encodes a calcium-dependent cell adhesion protein critical for photoreceptor cell adhesion in retina and stereocilia organization in inner ear; mutations cause Usher syndrome type 1F (hearing loss + retinitis pigmentosa) and nonsyndromic deafness. The 20 pathogenic variants include frameshift deletions (p.Ile43fs, p.Gly37fs, p.Asp47fs), nonsense mutations (p.Glu49Ter), missense (p.Arg51Gln), and splice site alterations. Absence from UniProt, STRING, and HPA databases confirms this is not a canonical protein-coding gene. The genomic span (~170kb) is consistent with either a large non-coding RNA or regulatory region encompassing multiple PCDH15 exons/enhancers.
