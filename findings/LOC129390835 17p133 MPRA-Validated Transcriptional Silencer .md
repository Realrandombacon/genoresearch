# LOC129390835: 17p13.3 MPRA-Validated Transcriptional Silencer with Strong Triplosensitivity

**Date:** 2026-03-19T03:05:16.995045

**Quality Score:** 3.0/10  (E=4.1, D=1.9) [WEAK]

## Description
LOC129390835 is a functionally characterized cis-regulatory element on chromosome 17p13.3 (genomic coordinates: 8807110-8807436 on NC_000017.11, spanning approximately 326 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 4 pathogenic/likely pathogenic variants with strong triplosensitivity: ALL 4 variants are copy number gains (duplications), with 0 deletions, indicating extreme triplosensitivity where increased copy number is the exclusive pathogenic mechanism. This 100% duplication bias contrasts with mixed dosage sensitivity patterns seen in other silencers (LOC129390899: 3 deletions/2 duplications; LOC129391066: mixed). The 17p13 chromosomal region contains critical dosage-sensitive genes including TP53 (tumor protein p53 - cell cycle checkpoint, tumor suppressor), PAFAH1B1/LIS1 (lissencephaly-1 - neuronal migration, brain development), and YWHA14 (14-3-3 protein). As an experimentally validated silencer, LOC129390835 likely functions to repress transcription of target genes in cis during erythroid differentiation. Duplication of this silencer causes excessive repression of target genes, potentially contributing to 17p13 duplication syndrome phenotypes including developmental delay, intellectual disability, and craniofacial abnormalities. The exclusive triplosensitivity pattern suggests this element may regulate TP53 or LIS1 expression dosage critically.
