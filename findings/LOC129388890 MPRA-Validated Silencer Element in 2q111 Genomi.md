# LOC129388890: MPRA-Validated Silencer Element in 2q11.1 Genomic Region with Chromosomal Rearrangement Syndrome Association

**Date:** 2026-03-23T07:35:14.669457

**Quality Score:** 3.4/10  (E=3.6, D=3.2) [WEAK]

## Description
LOC129388890 (Gene ID: 129388890) is a functionally validated cis-regulatory silencer element mapping to chromosome 2q11.1 (95,766,487-95,766,687 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak3793 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 4 pathogenic copy number variants including 2q11.1-11.2 deletion (2.2 Mb), 2q11.1-13 duplication (15.9 Mb), 2q11.1-12.1 duplication (8.4 Mb), and 2p11.2-q11.2 duplication (10.9 Mb) - 2q rearrangements cause developmental delay, intellectual disability, craniofacial dysmorphism, cardiac defects, and growth retardation; (4) No HPA expression expected (non-coding); (5) No STRING interactions or InterPro domains (non-coding). The 2q11 region contains critical developmental genes: PAX3 (2q35, paired box transcription factor, Waardenburg syndrome), multiple immunoglobulin kappa light chain genes (IGKC, 2q11.1, B-cell receptor), and HOXD cluster (2q31, embryonic patterning). 2q11 rearrangements are recurrent in B-cell malignancies and developmental disorders. Mechanistic hypothesis: LOC129388890 functions as a transcriptional silencer that represses gene expression in hematopoietic or developmental contexts. The element likely recruits co-repressor complexes (e.g., Polycomb repressive complex 2, NuRD, or HDAC-containing complexes) via sequence-specific DNA-binding proteins to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 2q11.1 is gene-dense with immunoglobulin loci and developmental regulators; silencer disruption via CNVs alters TAD architecture and long-range regulation of IGKC, neighboring transcription factors, and developmental genes. Immunoglobulin locus dysregulation causes B-cell malignancies; 2q rearrangements cause haploinsufficiency of multiple dosage-sensitive genes. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes.
