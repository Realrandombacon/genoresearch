# LOC129390241: MPRA-Validated Silencer Element in 10q26.3 Region with 38 Pathogenic CNVs Linked to 10q26 Deletion Syndrome

## Description
LOC129390241 (Gene ID: 129390241) is a functionally validated cis-regulatory silencer element mapping to chromosome 10q26.3 (133,080,151-133,080,351 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak1134 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 38 pathogenic copy number variants involving 10q26 region - predominantly deletions (10q26.2-26.3, 10q26.13-26.3 ranging 1.5-11 Mb) and some duplications; (4) No HPA expression expected (non-coding); (5) No STRING interactions (non-coding). The 10q26 region is clinically critical - 10q26 deletion syndrome is the most common terminal deletion disorder. Critical 10q26 region contains: FGFR2 (fibroblast growth factor receptor 2, craniosynostosis, Apert/Crouzon/Pfeiffer syndromes), PTEN (phosphatase and tensin homolog, tumor suppressor, Cowden syndrome, Bannayan-Riley-Ruvalcaba syndrome), MGMT (O-6-methylguanine-DNA methyltransferase, DNA repair), BMPR2 (bone morphogenetic protein receptor 2, pulmonary arterial hypertension), and multiple neurodevelopmental genes. Mechanistic hypothesis: LOC129390241 functions as transcriptional silencer that represses gene expression in hematopoietic or developmental contexts. The element likely recruits co-repressor complexes (Polycomb repressive complex 2, NuRD, HDAC-containing complexes, DNA methyltransferases) via sequence-specific DNA-binding proteins (CTCF, ZNF proteins) to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 10q26 deletion syndrome phenotype includes: intellectual disability, developmental delay, distinctive facial features (prominent forehead, downslanting palpebral fissures, low-set ears), skeletal anomalies (clinodactyly, radioulnar synostosis), genitourinary malformations, and growth restriction. Silencer disruption via 10q26 CNVs alters TAD architecture and long-range enhancer-promoter contacts - affecting FGFR2 dosage (craniosynostosis, skeletal dysplasia), PTEN expression (tumor predisposition, macrocephaly), and chromatin domain organization. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements in developmental disorder loci.
