# LOC129390259: MPRA-Validated Silencer Element in 11p15.4 Imprinted Domain with Beckwith-Wiedemann and Silver-Russell Syndrome Association

**Date:** 2026-03-23T07:44:23.771541

**Quality Score:** 3.2/10  (E=4.2, D=2.2) [WEAK]

## Description
LOC129390259 (Gene ID: 129390259) is a functionally validated cis-regulatory silencer element mapping to chromosome 11p15.4 (10,849,868-10,850,068 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak1197 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 2 pathogenic copy number variants involving 11p15.4-15.2 region - deletion (6.8 Mb) and duplication (18.5 Mb); (4) No HPA expression expected (non-coding); (5) No STRING interactions or InterPro domains (non-coding). The 11p15.5-15.4 region is clinically critical - this imprinted domain contains two major imprinting control regions (ICR1/H19-IGF2 and ICR2/KCNQ1OT1). 11p15.5 microduplication causes Beckwith-Wiedemann syndrome (OMIM #130650) - overgrowth, macroglossia, abdominal wall defects, embryonal tumors; 11p15.5 microdeletion causes Silver-Russell syndrome (OMIM #616488) - growth restriction, triangular face, body asymmetry. Critical 11p15 region contains: H19 (lncRNA, tumor suppressor), IGF2 (insulin-like growth factor 2, growth promoter), CDKN1C (p57KIP2, cell cycle inhibitor), KCNQ1 (potassium channel, Long QT syndrome), KCNQ1OT1 (lncRNA, imprinting regulator), and WT1 (Wilms tumor suppressor). Mechanistic hypothesis: LOC129390259 functions as a transcriptional silencer that represses gene expression in hematopoietic or developmental contexts. The element likely recruits co-repressor complexes (Polycomb repressive complex 2, NuRD, HDAC-containing complexes, DNA methyltransferases) via sequence-specific DNA-binding proteins (CTCF, ZNF proteins) to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 11p15.4 is gene-dense with imprinted growth regulators (H19/IGF2 antithetic expression), cell cycle inhibitors (CDKN1C), and tumor suppressors (WT1). Silencer disruption via CNVs alters TAD architecture and imprinting control - affecting H19/IGF2 reciprocal expression (overgrowth vs growth restriction), CDKN1C dosage (cell cycle dysregulation), and KCNQ1OT1-mediated silencing (KCNQ1 cluster). Imprinting defects cause parent-of-origin effects - paternal uniparental disomy causes BWS; maternal uniparental disomy causes SRS. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements in imprinted domains.
