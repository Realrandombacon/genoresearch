## Description
LOC126861449 is an uncharacterized cis-regulatory element (CRE) at chromosome 12p13.33 (genomic coordinates 10941909-10943108, ~1.2kb span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through STARR-seq massively parallel reporter assays (MPRAs). The gene_info summary identifies this as a MED14-INDEPENDENT GROUP 3 ENHANCER that was experimentally validated in HCT116 colorectal carcinoma cells. Critically, this enhancer depends on BRD2, BRD4, P300/CBP, and CDK7 cofactors but shows LIMITED OR NO DEPENDENCE on the MED14 core Mediator complex subunit. This cofactor profile distinguishes it from canonical Mediator-dependent enhancers and suggests it operates through BET-dependent chromatin remodeling mechanisms independent of core Mediator recruitment. ClinVar contains 12 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. STRIKINGLY, this locus shows EXCLUSIVE AMPLIFICATION pathogenicity: ALL 12 variants are copy number GAINS (chr12:64621-34650483x3, chr12:82453-49847230x3, chr12:64620-34682902x4, chr12:1258274-20657577x3, chr12:54427-34608071x4, chr12:121271-133196807x3, chr12:121271-34603261x3, chr12:2871741-14987348x3, chr12:121255-34603274x3, chr12:212976-33926913x4, and additional amplifications), with ZERO copy number losses. This exclusive amplification pattern contrasts with bidirectional enhancers and suggests this element regulates an oncogene where only amplification drives disease (or a tumor suppressor where amplification causes silencing via position effect). Four tetrasomy (4 copies) events indicate extreme oncogenic selection pressure. The 12p region contains KRAS (12p12.1), the most frequently mutated oncogene in pancreatic, colorectal, and lung cancers, as well as CCND2 (cyclin D2) and other cell cycle regulators. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with strong oncogenic relevance — the BRD2/BRD4/P300/CBP/CDK7-dependent but MED14-independent enhancer activity combined with exclusive amplification pathogenicity suggests LOC126861449 functions as an oncogene-specific enhancer (potentially for KRAS or CCND2) where only amplification drives oncogenic overexpression.
