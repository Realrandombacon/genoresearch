## Description
LOC129388553 is a functionally characterized cis-regulatory element on chromosome 1p31.3 (genomic coordinates: 76843949-76844149 on NC_000001.11, spanning approximately 200 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 3 pathogenic/likely pathogenic variants with extreme haploinsufficiency: ALL 3 variants are copy number losses (deletions, 100%), with 0 duplications, indicating haploinsufficiency is the exclusive pathogenic mechanism. This 100% deletion bias represents the strongest haploinsufficiency signal observed in this silencer series, contrasting sharply with triplosensitivity silencers (LOC129390835: 100% duplications; LOC129390366: 100% duplications). The 1p31 chromosomal region contains critical dosage-sensitive genes including PEX11B (peroxisome biogenesis factor - peroxisome proliferation, lipid metabolism), MLLT3/AF9 (myeloid/lymphoid translocation partner - leukemia translocations, chromatin regulation), GADD45A (growth arrest and DNA damage inducible alpha - cell cycle checkpoint, DNA repair), and multiple developmental transcription factors. As an experimentally validated silencer, LOC129388553 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially DNA damage response regulation. Loss of this silencer causes derepression/overexpression of target genes (potentially GADD45A or PEX11B), contributing to 1p31 deletion syndrome phenotypes including developmental delay, metabolic disturbances (via peroxisome pathway), and genomic instability (via DNA damage response pathway). The extreme haploinsufficiency pattern suggests this element regulates tumor suppressors or cell cycle checkpoints where loss of repression drives pathogenic overexpression.
