# LOC129391107: 19q13.1 MPRA-Validated Transcriptional Silencer with Triplosensitivity

**Date:** 2026-03-19T03:03:20.395051

**Quality Score:** 2.45/10  (E=3.4, D=1.5) [WEAK]

## Description
LOC129391107 is a functionally characterized cis-regulatory element on chromosome 19q13.1 (genomic coordinates: 38569315-38569515 on NC_000019.10, spanning approximately 200 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 2 pathogenic/likely pathogenic variants, both copy number gains (duplications), indicating triplosensitivity where increased copy number causes disease. The 19q13 chromosomal region contains critical dosage-sensitive genes including ZNF595 (zinc finger protein), PDCD1 (programmed cell death 1 - immune checkpoint), LCN1 (lipocalin 1), and multiple zinc finger transcription factors. As an experimentally validated silencer, LOC129391107 likely functions to repress transcription of target genes in cis during erythroid differentiation. Duplication of this silencer element may cause excessive repression of target genes, leading to haploinsufficiency-like phenotypes despite copy number gain. This 200 bp silencer may regulate genes involved in erythroid development, immune function, or chromatin remodeling. The MPRAs validation in K562 cells suggests hematologic relevance, potentially contributing to 19q13 duplication syndrome phenotypes including developmental delay and immune abnormalities.
