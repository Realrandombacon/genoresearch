# LRRC14B: PRAME Family LRR Protein with 130 Pathogenic Variants, Muscle-Enriched Expression and Cancer-Testis Antigen Properties

## Description
LRRC14B (UniProt A6NHZ5, 514 aa) is a leucine-rich repeat (LRR) containing protein belonging to the PRAME (PReferentially expressed Antigen in MElanoma) family, mapping to chromosome 5p15.33 (191,494-196,333 bp, ~5 kb). Domain architecture: N-terminal PRAME domain (PF27091, residues 11-113), central LRR domain superfamily (IPR032675, G3DSA:3.80.10.10 ribonuclease inhibitor fold, residues 168-424), and C-terminal PRAME domain (PF27089, IPR060377, residues 268-444). The LRR domain mediates protein-protein interactions via curved solenoid structure with β-strand/α-helix repeats. STRING interactions confirm functional partnerships with LRR-containing proteins: LRRC30 (0.609), ASB12 (0.585, ankyrin SOCS box ubiquitin ligase), LRRC20 (0.547), plus TMEM191B (0.505), CCDC127 (0.499), TMEM236 (0.498), PLEKHG4B (0.480), IQCA1L (0.474), TMEM38A (0.442), OR13C8 (0.516). HPA shows group-enriched expression in skeletal muscle (106.6 nTPM) and heart muscle (39.2 nTPM), cancer-enriched pattern, nucleoplasmic/cytosolic localization. Clinical significance is extensive: ClinVar contains 130 pathogenic/likely pathogenic variants, predominantly copy number variants affecting 5p15.33-15.2 region (deletions ranging 3.6-26.4 Mb, duplications 31.8 Mb). 5p15.33 is telomeric region containing TERT (telomerase reverse transcriptase), CTNND2 (catenin delta-2, neuronal development), and multiple cancer-testis antigen genes. PRAME family proteins function as transcriptional repressors recruiting polycomb repressive complex (PRC2) via interaction with EZH2, and as substrate recognition components of ECS (Elongin-Cullin-SOCS box) E3 ubiquitin ligase complexes. Mechanistic hypothesis: LRRC14B functions as dual-function regulator - (1) transcriptional corepressor via PRAME domain recruiting PRC2/HDAC complexes to silence differentiation genes in stem/progenitor cells; (2) ubiquitin ligase substrate adaptor via SOCS box interaction (ASB12 partnership) targeting specific substrates for proteasomal degradation. Muscle-enriched expression suggests role in myogenesis, sarcomere maintenance, or muscle regeneration. Cancer-enriched pattern indicates potential oncogenic function via cell cycle deregulation, stemness maintenance, or immune evasion. 5p deletions cause cri-du-chat syndrome (5p- syndrome) - LRRC14B haploinsufficiency may contribute to muscular hypotonia, cardiac defects, and developmental delay. Conservation: mouse ortholog (Q3UJB3, 510 aa, ~99% identity), zebrafish ortholog (Q1L8H0, 526 aa, ~97% identity).
