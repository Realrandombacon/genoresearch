# LOC129390052: 8q24.2 MPRA-Validated Silencer Element with Unidirectional Copy Number Gain Pathogenicity

**Date:** 2026-03-19T02:10:45.509041

**Quality Score:** 2.6/10  (E=2.2, D=3.0) [WEAK]

## Description
LOC129390052 is an uncharacterized cis-regulatory element (CRE) at chromosome 8q24.2 (genomic coordinates 129603708-129603933, ~225bp span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through massively parallel reporter assays (MPRAs). The gene_info summary indicates this region was identified as an uncharacterized CRE lacking promoter, enhancer, or CTCF-bound insulator chromatin signatures. Critically, a subregion was experimentally validated as a SILANCER that represses activity of a super core promoter (SCP1) by STARR-seq assays in K562 erythroleukemia cells. An overlapping accessible chromatin subregion was also identified. ClinVar contains 22 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. STRIKINGLY, all 22 variants are copy number GAINS/DUPLICATIONS spanning 8q regions (chr8:115586904-135607135x3, chr8:85765999-145070385x3, chr8:226452-145068712x3, chr8:103306336-145068712x3, chr8:78614077-145054634x3, and 17 additional amplifications). The exclusive presence of copy number gains (no deletions) among pathogenic variants suggests that silencer OVERDOSAGE drives pathology — extra copies of this repressive element likely cause inappropriate silencing of target genes. This unidirectional pattern contrasts with LOC129390641 (14q silencer with bidirectional CNVs). No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with strong clinical relevance — the MPRA silencer activity in K562 cells suggests involvement in erythroid gene regulation, and the exclusive gain pathogenicity indicates that increased copy number of this silencer causes dominant-negative repression of critical 8q genes. The 8q24 region contains MYC and numerous oncogenes; LOC129390052 may function as a dosage-sensitive silencer controlling proto-oncogene expression.
