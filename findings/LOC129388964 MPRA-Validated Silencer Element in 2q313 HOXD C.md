# LOC129388964: MPRA-Validated Silencer Element in 2q31.3 HOXD Cluster Region

## Description
LOC129388964 (Gene ID: 129388964) is not a protein-coding gene but a functionally validated cis-regulatory silencer element mapping to chromosome 2q31.3 (181,944,207-181,944,407 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak3964 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 14 pathogenic copy number variants (large 2q deletions/duplications spanning 10-50 Mb), associated with 2q deletion syndromes featuring limb anomalies, intellectual disability, and craniofacial dysmorphism. The 2q31.3 region contains the HOXD homeobox gene cluster (HOXD1, HOXD3, HOXD4, HOXD8, HOXD9, HOXD10, HOXD11, HOXD12, HOXD13) critical for limb and digit development, plus EVX2 (even-skipped homeobox 2). Mechanistic hypothesis: LOC129388964 functions as a transcriptional silencer that represses HOXD cluster or neighboring developmental gene expression in hematopoietic or limb bud contexts. The element likely recruits co-repressor complexes (e.g., Polycomb repressive complex 2, NuRD, or HDAC-containing complexes) via sequence-specific DNA-binding proteins (e.g., HOX cofactors PBX/MEIS, or limb-specific transcription factors) to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). Pathogenic 2q CNVs disrupt silencer-enhancer balance and chromatin topology (TAD boundaries), causing HOXD cluster misexpression and limb malformations (synpolydactyly, brachydactyly). The 2q31.3 locus is a known limb development critical region—HOXD13 mutations cause synpolydactyly type II. Altered silencer function may contribute to HOXD dysregulation and limb phenotypes. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes due to automated pipeline predictions. The MPRA validation provides direct functional evidence of regulatory activity in erythroid lineage.
