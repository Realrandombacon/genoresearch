# LOC129390641: 14q11.2 MPRA-Validated Silencer Element with Copy Number Pathogenicity

**Date:** 2026-03-19T02:10:11.592195

**Quality Score:** 2.25/10  (E=1.8, D=2.7) [WEAK]

## Description
LOC129390641 is an uncharacterized cis-regulatory element (CRE) at chromosome 14q11.2 (genomic coordinates 70053070-70053278, ~208bp span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through massively parallel reporter assays (MPRAs). The gene_info summary indicates this region was identified as an uncharacterized CRE lacking promoter, enhancer, or CTCF-bound insulator chromatin signatures. Critically, a subregion was experimentally validated as a SILANCER that represses activity of a super core promoter (SCP1) by STARR-seq assays in K562 erythroleukemia cells. An overlapping accessible chromatin subregion was also identified. ClinVar contains 3 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements: two copy number gains duplicating 14q11.2-32.33 (chr14:20043514-106877229x3, chr14:20151149-106855263x3) and one copy number loss deleting 14q24.1-31.1 (chr14:69562099-81975384x1). The presence of both gains and losses among pathogenic variants suggests dosage sensitivity of this regulatory element. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with functional validation — the MPRA silencer activity in K562 cells suggests involvement in erythroid gene regulation, and the CNV pathogenicity indicates that precise copy number of this silencer is required for normal development. The 14q11.2-32.33 region contains numerous genes involved in T-cell receptor rearrangement and immune function. LOC129390641 may function as a lineage-specific silencer controlling expression of neighboring genes in hematopoietic cells.
