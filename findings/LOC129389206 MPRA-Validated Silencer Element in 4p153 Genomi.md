# LOC129389206: MPRA-Validated Silencer Element in 4p15.3 Genomic Region with Wolf-Hirschhorn Syndrome Association

**Date:** 2026-03-23T07:36:10.939616

**Quality Score:** 3.65/10  (E=4.1, D=3.2) [MODERATE]

## Description
LOC129389206 (Gene ID: 129389206) is a functionally validated cis-regulatory silencer element mapping to chromosome 4p15.3 (36,613,253-36,613,453 bp, ~200 bp span). RefSeq annotation explicitly states: "MPRA-validated peak5020 silencer" - validated by STARR-seq massively parallel reporter assays in K562 erythroleukemia cells as repressing super core promoter SCP1 activity. Multiple evidence lines confirm non-coding regulatory function: (1) No UniProt accession (not a protein); (2) Genomic span of 200 bp is far too small for protein-coding gene; (3) ClinVar contains 7 pathogenic copy number variants all involving 4p deletions/duplications - 4p16.3-q12 duplication (57 Mb), 4p16.3-13 duplication (40 Mb), 4p16.3-11 duplication (49 Mb), 4p15.33-14 deletion (26.7 Mb), 4p16.3-12 duplication (47.5 Mb), 4p16.3-14 duplications (39.4 Mb and 38.6 Mb); (4) No HPA expression expected (non-coding); (5) No STRING interactions or InterPro domains (non-coding). The 4p region is clinically critical - deletions cause Wolf-Hirschhorn syndrome (WHS, OMIM #194090) characterized by severe intellectual disability, growth retardation, distinctive "Greek warrior helmet" craniofacial appearance, seizures, and congenital heart defects. Critical WHS region contains: WHSC1 (nuclear receptor binding SET domain protein, histone methyltransferase), LETM1 (mitochondrial inner membrane protein, seizure susceptibility), FGFRL1 (FGF receptor decoy, skeletal development), and multiple developmental transcription factors. 4p rearrangements are recurrent in hematologic malignancies and developmental disorders. Mechanistic hypothesis: LOC129389206 functions as a transcriptional silencer that represses gene expression in hematopoietic or developmental contexts. The element likely recruits co-repressor complexes (Polycomb repressive complex 2, NuRD, HDAC-containing complexes) via sequence-specific DNA-binding proteins to establish repressive chromatin (H3K27me3, H3K9me3, DNA methylation). K562 erythroleukemia validation suggests activity in erythroid/myeloid lineage. 4p15.3 is gene-dense with developmental regulators and immunoglobulin heavy chain locus (IGH@, 4p16.3). Silencer disruption via CNVs alters TAD architecture and long-range regulation of WHSC1, LETM1, FGFRL1, and neighboring developmental genes. Haploinsufficiency of these dosage-sensitive genes causes WHS phenotype; duplication causes milder but overlapping developmental delays. This represents a critical class of "dark genes" that are actually functional non-coding regulatory elements misannotated as genes.
