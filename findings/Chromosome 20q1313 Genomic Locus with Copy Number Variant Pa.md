## Description
LOC105372653 is an uncharacterized genomic locus on chromosome 20q13.13 (GRCh38: 49,915,821-49,928,820 bp) that lacks canonical protein-coding annotation. No UniProt accession exists, preventing InterPro domain analysis, AlphaFold structure prediction, and STRING interaction mapping. Human Protein Atlas could not resolve this locus to an Ensembl ID, suggesting absent or undetected protein expression. However, ClinVar documents 3 pathogenic/likely pathogenic copy number variants in this region: two copy number gains (chr20:99,557-64,277,321 and chr20:44,787,704-64,277,321) and one copy number loss (chr20:49,731,076-51,202,566). The pathogenicity of these structural variants indicates functional importance despite lack of protein annotation. PubMed search returned zero publications, confirming this remains a true "dark" genomic region. The 20q13.13 amplicon is a known cancer hotspot containing oncogenes like AURKA and TOP1; LOC105372653 may represent a regulatory element, non-coding RNA, or alternative ORF within this amplified region. Hypothesis: This locus functions as a cis-regulatory element or encodes a micropeptide that modulates 20q13 amplification-driven oncogenesis. Copy number alterations disrupt this regulatory function, contributing to genomic instability in cancers with 20q13 gains.
