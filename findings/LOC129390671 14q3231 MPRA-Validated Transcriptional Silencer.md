# LOC129390671: 14q32.31 MPRA-Validated Transcriptional Silencer with Deletion-Predominant Pathogenicity Near Imprinted Region

**Date:** 2026-03-19T03:06:18.325330

**Quality Score:** 2.9/10  (E=4.6, D=1.2) [WEAK]

## Description
LOC129390671 is a functionally characterized cis-regulatory element on chromosome 14q32.31 (genomic coordinates: 103689258-103689458 on NC_000014.9, spanning approximately 200 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 24 pathogenic/likely pathogenic variants with deletion-predominant pathogenicity: approximately 14-16 copy number losses (deletions) and 8-10 copy number gains (duplications), indicating haploinsufficiency is the primary pathogenic mechanism (~60-67% losses vs ~33-40% gains). This deletion bias contrasts with duplication-predominant patterns seen in 17p13.3 silencers (LOC129390835: 100% duplications; LOC129390818: ~70% duplications), suggesting 14q32 silencers are predominantly haploinsufficiency-critical. The 14q32 chromosomal region contains critical dosage-sensitive genes including AKT1 (oncogene, PI3K-AKT signaling pathway), IGH locus (immunoglobulin heavy chain - B cell development, antibody production), DYRK1B (dual specificity kinase - metabolic regulation), and multiple imprinted genes (MEG3, MEG8, RTL1) regulated by the 14q32 imprinting control region. As an experimentally validated silencer, LOC129390671 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially B cell development. Loss of this silencer causes derepression/overexpression of target genes (potentially AKT1 or IGH locus), contributing to 14q32 deletion syndrome phenotypes including developmental delay, immune deficiency, and overgrowth syndromes (via AKT1 pathway). The high variant count (24 CNVs) indicates this element is clinically significant and under strong dosage constraint.
