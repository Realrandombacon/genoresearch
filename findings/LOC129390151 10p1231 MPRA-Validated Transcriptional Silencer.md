## Description
LOC129390151 is a functionally characterized cis-regulatory element on chromosome 10p12.31 (genomic coordinates: 21888885-21889103 on NC_000010.11, spanning approximately 218 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 2 pathogenic/likely pathogenic variants with pure triplosensitivity: BOTH variants are copy number gains (duplications, 100%), with 0 deletions, indicating extreme triplosensitivity where increased copy number is the exclusive pathogenic mechanism. This 100% duplication bias matches the strongest triplosensitivity signals observed in this silencer series (LOC129390835, LOC129390366). The 10p12-13 chromosomal region contains critical dosage-sensitive genes including GATA3 (GATA binding protein 3 - T cell development, HDR syndrome: hypoparathyroidism, deafness, renal dysplasia), ANKRD26 (ankyrin repeat domain 26 - thrombocytopenia predisposition), SRF (serum response factor - actin cytoskeleton, cell proliferation), and TRRAP (transformation/transactivation domain protein - chromatin remodeling, DNA repair). As an experimentally validated silencer, LOC129390151 likely functions to repress transcription of target genes in cis during erythroid and lymphoid differentiation. Duplication of this silencer causes excessive repression of target genes (potentially GATA3 or ANKRD26), contributing to 10p deletion/duplication syndrome phenotypes including developmental delay, immune deficiency, thrombocytopenia, and renal/auditory abnormalities (via GATA3 pathway). The pure triplosensitivity pattern suggests this element regulates hematopoietic transcription factors where precise dosage is critical for lineage commitment.
