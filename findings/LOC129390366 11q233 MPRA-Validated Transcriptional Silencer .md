## Description
LOC129390366 is a functionally characterized cis-regulatory element on chromosome 11q23.3 (genomic coordinates: 116980228-116980447 on NC_000011.10, spanning approximately 219 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 9 pathogenic/likely pathogenic variants with extreme triplosensitivity: ALL 9 variants are copy number gains (duplications, 100%), with 0 deletions, indicating extreme triplosensitivity where increased copy number is the exclusive pathogenic mechanism. This 100% duplication bias matches LOC129390835 (100% duplications) as the strongest triplosensitivity signal observed in this silencer series. The 11q23 chromosomal region contains critical dosage-sensitive genes including KMT2A/MLL (histone lysine methyltransferase - chromatin modification, leukemia translocations), ATM (ataxia telangiectasia mutated - DNA damage response, cell cycle checkpoint), POU2F2 (POU domain transcription factor - B cell development), and multiple developmental regulators. As an experimentally validated silencer, LOC129390366 likely functions to repress transcription of target genes in cis during erythroid differentiation and potentially hematopoietic stem cell regulation. Duplication of this silencer causes excessive repression of target genes (potentially KMT2A or ATM), contributing to 11q23 duplication syndrome phenotypes including developmental delay, intellectual disability, hematologic abnormalities, and potential leukemia predisposition. The extreme triplosensitivity pattern suggests this element regulates chromatin modifiers or DNA damage response genes where precise dosage is critical for genomic stability and hematopoiesis.
