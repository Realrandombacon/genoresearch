## Description
LOC126859607 is an uncharacterized cis-regulatory element (CRE) at chromosome 6p23 (genomic coordinates 17340828-17342027, ~1.2kb span). This locus is NOT a protein-coding gene but a functional regulatory DNA element validated through STARR-seq massively parallel reporter assays (MPRAs). The gene_info summary identifies this as a BRD4-INDEPENDENT GROUP 4 ENHANCER that was experimentally validated in HCT116 colorectal carcinoma cells. Critically, this enhancer depends on BRD2, P300/CBP, MED14, and CDK7 cofactors but shows LIMITED OR NO DEPENDENCE on the BRD4 bromodomain protein. This cofactor profile distinguishes it from canonical BET-dependent enhancers and suggests it operates through BRD2-dependent chromatin remodeling mechanisms that bypass BRD4 requirement. ClinVar contains 5 pathogenic/likely pathogenic variants affecting this locus through large-scale chromosomal rearrangements. This locus shows BIDIRECTIONAL pathogenicity: 3 copy number GAINS (chr6:156974-46789291x3, chr6:3224310-30657190x3, chr6:106431-18360595x3) AND 2 copy number LOSSES (chr6:12020008-22846454x1, chr6:14730556-17554091x1). This bidirectional pattern indicates strict dosage requirements. The 6p region contains critical immune and developmental genes including FOXP3 (6p22.3, forkhead box P3, regulatory T cell transcription factor), TAP1 (6p21.3, transporter associated with antigen processing), and multiple MHC class I genes. No UniProt accession exists (non-coding DNA), STRING found no interactions (not a protein), HPA could not resolve (not protein-coding), and PubMed has zero publications for this specific locus. This represents a genuine dark regulatory element with clinical relevance — the BRD2/P300/CBP/MED14/CDK7-dependent but BRD4-independent enhancer activity combined with bidirectional pathogenicity suggests LOC126859607 functions as a dosage-critical enhancer controlling 6p immune/developmental gene expression, where the BRD4-independence suggests this enhancer may remain active even when BET inhibitors target BRD4.
