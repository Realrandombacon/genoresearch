# LOC129388872: 2p16.1 MPRA-Validated Transcriptional Silencer with Deletion-Predominant Pathogenicity Near BCL11A/FANCB Region

**Date:** 2026-03-19T03:10:48.512994

**Quality Score:** 3.45/10  (E=5.4, D=1.5) [WEAK]

## Description
LOC129388872 is a functionally characterized cis-regulatory element on chromosome 2p16.1 (genomic coordinates: 62129599-62129799 on NC_000002.12, spanning approximately 200 bp). This genomic region was experimentally validated as a transcriptional silencer using STARR-seq massively parallel reporter assays (MPRAs) in K562 erythroleukemia cells, demonstrating ability to repress activity of super core promoter SCP1. The element lacks protein-coding evidence (no UniProt entry, no STRING interactions, no HPA protein expression), confirming its identity as a non-coding regulatory element. The accessible chromatin subregion annotation indicates active regulatory function in hematopoietic cell lineages. ClinVar analysis identified 7 pathogenic/likely pathogenic variants with deletion-predominant pathogenicity: 5 copy number losses (deletions, 71%) and 2 copy number gains (duplications, 29%), indicating haploinsufficiency is the primary pathogenic mechanism. This 71% deletion bias is consistent with other haploinsufficiency-critical silencers (LOC129390296: 80% deletions; LOC129389855: 75% deletions). The 2p16 chromosomal region contains critical dosage-sensitive genes including BCL11A (B-cell lymphoma/leukemia 11A - hemoglobin switching, sickle cell disease therapeutic target), FANCB (Fanconi anemia complementation group B - DNA interstrand crosslink repair, X-linked Fanconi anemia), REL (proto-oncogene, NF-kappaB signaling), and ACVR1B (activin receptor type 1B - TGF-beta signaling). As an experimentally validated silencer, LOC129388872 likely functions to repress transcription of target genes in cis during erythroid and B-cell differentiation. Loss of this silencer causes derepression/overexpression of target genes (potentially BCL11A or FANCB), contributing to 2p16 deletion syndrome phenotypes including developmental delay, hematologic abnormalities (via BCL11A pathway), DNA repair deficiency (via FANCB), and increased cancer predisposition. The haploinsufficiency pattern suggests this element regulates hematopoietic transcription factors or DNA repair genes where loss of repression is pathogenic.
