# LOC113939919: 11q Repressive Enhancer with Duplication-Predominant Dosage Sensitivity

## Description
LOC113939919 is a Sharpr-MPRA regulatory region 8002 located on chromosome 11q23.2 (genomic coordinates: 116379431-116379738 on NC_000011.10). This 308 bp genomic sequence was predicted as a transcriptional regulatory region based on ENCODE chromatin state analysis and experimentally validated as a functional repressive element (silencer) using Sharpr-MPRA in HepG2 liver carcinoma cells. As a non-coding regulatory element, it lacks protein-coding potential (no UniProt entry, no InterPro domains, no AlphaFold structure, no STRING interactions, no HPA protein expression). ClinVar analysis identified 3 pathogenic/likely pathogenic variants: all 3 are copy number gains (duplications), indicating strong duplication-predominant dosage sensitivity. The variant count (3 vs 8 for LOC113939947, 7 for LOC113939953, 4 for LOC113939933, 3 for LOC113960610, 11 for LOC113939970, 21 for LOC114004412) suggests moderate-to-low clinical penetrance. The 11q chromosomal region contains critical genes including ATM (ataxia telangiectasia mutated - DNA damage response), MLL1/KMT2A (histone methyltransferase - leukemia translocations), POU2F2 (POU domain transcription factor), and multiple immune/metabolic genes. As a repressive enhancer/silencer, this element likely suppresses expression of one or more target genes in cis within the 11q domain. The duplication-predominant pathogenicity pattern (3 gains, 0 losses) mirrors the pattern seen in LOC113939933 (12q silencer) - suggests these silencers normally repress tumor suppressors or differentiation genes where increased silencer dosage leads to target gene underexpression. This element may contribute to 11q duplication syndromes, leukemia through MLL1 pathway dysregulation, or DNA damage response defects through ATM pathway effects.
