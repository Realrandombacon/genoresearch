# LOC129390646: MPRA-Validated Chromatin Silencer Element on Chromosome 14 with Clinical CNV Associations

**Date:** 2026-03-23T11:23:59.313163

**Quality Score:** 3.15/10  (E=4.5, D=1.8) [WEAK]

## Description
LOC129390646 is not a protein-coding gene but a cis-regulatory DNA element classified as a silencer, validated through massively parallel reporter assays (MPRAs) using STARR-seq technology in K562 erythroleukemia cells. This 200bp genomic region (chr14:74202172-74202372, GRCh38) demonstrated capacity to repress super core promoter (SCP1) activity, confirming its function as a transcriptional repressor element. Unlike protein-coding genes, LOC129390646 lacks UniProt accession, InterPro domains, and STRING interactions—expected for non-coding regulatory DNA. However, clinical significance is evident: ClinVar documents 6 pathogenic/likely pathogenic copy number variants (CNVs) spanning this locus, including both duplications (x3) and deletions (x1) across 14q24.3-32.33 regions. These CNVs suggest dosage sensitivity of this silencer element, where disruption may cause dysregulation of target genes through loss of repression. The absence of HPA expression data confirms non-protein-coding status. Hypothesis: LOC129390646 functions as a chromatin silencer that recruits repressive complexes (potentially Polycomb PRC2 or KRAB-ZNF co-repressors) to silence neighboring genes on chromosome 14. Its clinical CNV associations indicate that copy number alterations disrupt normal gene dosage regulation, potentially contributing to developmental disorders or hematologic malignancies. The K562 erythroid cell validation suggests particular relevance to blood cell development, where precise transcriptional silencing is critical for lineage commitment.
